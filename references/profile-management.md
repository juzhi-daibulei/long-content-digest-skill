# 场景信息管理（渐进式记忆）

## 核心原则：先给价值，再问要不要记

不在用户还没看到任何产出之前问任何问题。走完思考辅助路、展开完 Step 4 之后，如果这是本 skill 安装目录下第一次运行（没有 `user-context.md`），才顺嘴问一句：

> 如果以后想让我更贴合你的工作场景来想，可以顺嘴说一句你平时主要做什么——不说也没关系，不影响下次用。

用户不回答、说"不用"、或者换个话题，就此打住，不追问、不在下次继续问。这不是必答题。

## 存储位置

档案文件固定命名为 `user-context.md`，存放在**本 skill 的安装目录下**（跟 `SKILL.md` 同一层级，不是 `references/` 里面）。

**必须用绝对路径。** skill 被调用时上下文里会给出"Base directory for this skill: /真实的绝对路径"，把这行的绝对路径拼上 `/user-context.md` 就是档案路径，不要自己拼相对路径。

## 档案格式

```markdown
# 场景信息

- [用户回答的原话，不用整理成标签或分类]
- 记录时间：[YYYY-MM-DD]
```

不用把用户的回答强行归类成"岗位/行业/方向"这种字段，用户怎么说就怎么记，保持原话的信息量。

## 读写规则

- 每次 Step 5 之前，先安静地检查这个文件存不存在（Read 失败不用管是什么原因，也不用展示报错给用户），存在就在思考辅助路里自然用上，不用跟用户复述确认；不存在且是首次运行，才问那句话
- 用户主动说"更新一下我的场景/我换方向了"，重新问一句并覆盖原文件
- 不要每次都重新问或重新确认——档案存在的意义就是以后不用再问
